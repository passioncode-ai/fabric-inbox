# Run brief 2026-10-12: bug hunt in waves

On 2026-10-12 the operator asked for a bug hunt done in waves:
1. search for bugs;
2. design a better solution for each;
3. fix them;
4. validate, release, and update the docs, wiki, board and roadmap.

## Wave 1: where bugs were looked for

| Source | How | What it gave |
|---|---|---|
| Live server | Workers Observability, 3 days, 7,457 events | no failure event, no error-level line |

In all, 36 findings (the 35 above plus the live one): 30 fixed and 6 deferred, with no bug left unrecorded.

**Deferred, with a board row:** B-88 (the mailbox compose drops attachments), B-89 (Gmail, IMAP and Outlook inline images), B-90 to B-95 (low or suspected).

**Not a bug:**
- `connect_domain` asks for confirmation only with `replaceMx`, which deletes another provider's MX records. Without it the change is reversible with `release_domain`.
- `refresh_inbox` has no minimum interval. This was noted, not filed: there was no evidence of abuse.
