## How usable the project is today

- Locally, end to end on the real Worker with Miniflare bindings: create an agent, create a
  project address with it, deliver synthetic mail through the email handler, see the run.
- Nothing is deployed; no real provider, model, tool or delivery has been exercised. Workers
  AI has no local mode, so every local agent run fails closed and says so.
- Before this run the per-address agent never ran: `EMAIL_AGENT.fetch("/onNewEmail")` without
  the partyserver room header returned 500 and the error was not logged (backend #1).
