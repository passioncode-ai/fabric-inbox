## Target interface

### Screen: SCR-04 message reader (FLW-02/03)
- **Purpose:** act on one message — reply, reply all, forward, organize.
- **Elements:** Reply · **Reply all** (new, seeds To/Cc from all original participants minus the account's own address) · Forward · Rules · Discard (Not discarded in Discarded). AI panel toggle in the workbench header (see below).
- **States:** unchanged; the send flow keeps its pending/failed/uncertain states.
- **Behavior notes:** Reply all keeps thread identity exactly like Reply; unsupported cases hide rather than fail.

### Surface: workbench shell — AI panel (FLW-04)
- **Purpose:** ask AI about mail from the current inbox/reader (SCN-013).
- **Elements:** header toggle opens the agent sidebar on the unified inbox (mounted today only on legacy `/mailbox/:id`); narrow windows get an overlay sheet variant instead of `hidden lg:flex`.
- **States:** loading / empty+suggested prompts / **error: a failed model turn renders an error bubble with Retry that re-sends the last prompt** / streaming with Stop.
- **Behavior notes:** draft-only handoff stays ("Edit & send in composer"); source links deferred.

### Screen: SCR-07 automation rule editor (FLW-05)
- **Purpose:** author, dry-run, enable and pause a rule.
- **Elements:** existing form + rule row shows `v{n}` (version).
- **Behavior notes:** **Enable is disabled until a dry-run of the current form values succeeded** (FLW-05's gate); editing any field after a successful dry-run re-locks Enable.

### Screen: SCR-08 run history (FLW-06)
- **Purpose:** explain every run — source, rule version, attempts, actions, result, waiting reason.
- **Elements:** run card gains **rule version and attempt count**; cost shows an explicit "cost unavailable" label; list gains a loading branch; unknown runs gain a per-run "check status" affordance (P2).

### Screen: SCR-02 Settings forms
- **Signature (Name & signature):** leaving with unsaved edits asks first — wire the existing `useDirtyGuard` (pattern already used by Agents/Categories/Knowledge sections).
- **Agent editor (tool grants):** saving refuses a tool whose schema cannot be read, with the reason (server-side schema fetch at save time).
