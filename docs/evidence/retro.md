# Retrospective

## Standing instructions (max 10)

1. A Durable Object error class does not survive RPC — carry the code in the message (`workers/agents/errors.ts`).
2. Workers AI has no local mode: a local agent run must fail closed and say "safety check could not run", never report an injection.
3. `/agents/*` belongs to the agents SDK WebSocket; app pages go elsewhere (`/ai-agents`).
4. After new imports, restart `npm run dev` before judging a React "useCallback of null" error — it is Vite's pre-bundle, not the code.
5. In a Miniflare test, read or cancel each response body before the next `dispatchFetch`; an unread body can be reported as consumed under load.
6. A `srcdoc` iframe inherits the page's CSP: `frame-ancestors 'none'` blanks our own message reader (keep `'self'`, `tests/security-headers.test.ts`). Retired 2026-09-28: "a headless background tab does not lay out sandboxed iframes" — the blank reader was this header, not the tab.
7. A commit gate is the suite's exit code (`npm test > log; [ $? = 0 ]`), never a grep of its output.
8. A route is not done until its agent tool, the generated reference (`npm run mcp:docs`) and the skill in `plugins/fabric-inbox/` agree — `tests/mcp-coverage.test.ts`, `mcp-docs`, `mcp-skill` hold it (AGENTS.md, operator 2026-09-29). A workerd test that bundles the agents SDK marks `cloudflare:*` and `node:*` external and aliases `mimetext` to `mimetext/browser`, as wrangler does.

## Recent log

- 2026-09-30 — *Symptom:* the first trial 0.7.1 build stopped on "Gatekeeper did not accept the app as notarized (source=null)" for an app Apple had accepted. *Surfaced:* the build's new strict Gatekeeper check, on its first real run. *Owned by:* the builder's `tryRun`, which keeps stdout only on success, while `spctl` prints its verdict to stderr; the parser's unit tests fed it strings and never the real command. *Fix:* `spctl()` in `desktop/dist-mac.mjs` keeps both; `tests/dist-mac.test.ts` runs the real `spctl` on a system app (watched failing with the stdout-only reader). *Next time:* a check that reads a tool's output is tested once against the tool itself, not only against a string of what it is believed to print.
- 2026-09-29 — *Symptom:* the first 0.7.0 image was built as 0.6.2, with a 0.7.0 server inside that the app's own `bundleMatchesApp` would have refused to upload. *Surfaced:* stage 7, reading the image's receipt name. *Owned by:* the release step: `npm version` bumps the root `package.json` only, and nothing held `desktop/package.json` to it (0.6.3 had drifted the same way). *Fix:* d84ee43 (`tests/versions.test.ts` holds server, Mac app and skill plugin to one version; watched failing first). *Next time:* a version that several manifests carry is compared by a test, not remembered.
- 2026-09-29 — *Symptom:* making the first live agent key answered "Cloudflare: HTTP 403". *Surfaced:* stage 8, live. *Owned by:* stage 5 of the Cloudflare client: it recognised a permission refusal by code or by status without a code, and the Access API sends a code (1010) with no message. *Fix:* 4c61334, c37dee0 (an unexplained 403 names the permission; the route answers 403, not 502). *Next time:* an external API's refusal is tested with the exact body it sends, captured live.
- 2026-09-29 — *Symptom:* 0.6.0 shipped a spam purge that counted 30 days from a message's arrival, so Report spam on an old message deleted it within a second. *Surfaced:* the update audit run after the release, before any loss (the owner's Spam held two messages of that day). *Owned by:* stage 5 of SP-5: its only test backdated the arrival of mail that entered Spam on arrival, where the two clocks coincide. *Fix:* b48d2da (`spam_at`). *Next time:* a retention clock is tested on an item whose age and whose entry into the state differ.
- 2026-09-29 — *Symptom:* since CF-5 every app update of a server dropped its plain vars (catch-all policy, Gmail client id). *Surfaced:* the update audit. *Owned by:* the CF-5 deploy test, whose fake Worker settings held only `DOMAINS`, so "other settings kept" was never exercised. *Fix:* 9828524. *Next time:* a fake of an external store holds at least one value the code under test does not know about.
