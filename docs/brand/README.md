# Fabric Inbox brand pack

Draft calibration from [UX foundation](../ux/foundation.md) and existing English interface. No marketing positioning or new factual promise is approved here. The custom operational voice is proposed because wrong sender and uncertain actions carry real consequences; a playful alternative loses because it obscures recovery. Revisit after actual user feedback. Humanization uses the default own pass.

Read [voice](voice.md), [terms](terminology.md), [facts](facts.md), [channels](channels.md), and [strings](strings.md). Existing UI remains the source being inventoried; the registry now samples the integrated account, Gmail, rule/history and desktop strings. It records their actual source wording as proposed pending copy approval; it is not an exhaustive catalog.
