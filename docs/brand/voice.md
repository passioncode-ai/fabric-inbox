# Voice

## Axes
| Axis | The product IS | The product IS NOT |
|---|---|---|
| Confidence | precise about confirmed and unknown state | confident about unconfirmed delivery |
| Register | plain operational English | marketing language |
| Distance | direct and respectful | familiar or patronizing |
| Humor | absent in action and recovery copy | joking about loss or access |
| Density | concise with one next action | terse enough to omit consequences |

## Narrative
Hero: the owner handling their mail and authorized follow-up
Enemy: fragmented context and uncertain external actions
Product role: instrument
Promise: show the account, action and current result; this is a target behavior, not a launch claim

## Invariant in every language
- Never say sent until the provider confirms it.
- Distinguish unavailable, empty, waiting, failed and unknown.
- Keep the account identity and cached-data scope explicit in the unified workbench; light and dark themes use the same wording.
- Never claim draft preservation unless a save is confirmed.
- Use one name for each action and no unsourced numbers.

## Reconsidered per locale
Address form, idioms and line length; only English is currently specified.

## Failure mode
Over-compression: terse status labels omit what the user can do next. Keep the recovery action beside the state.

## Voice references
- **Admired:** current Fabric Inbox interface's short action labels, subject to factual state checks.
- **Refused:** generic assistant hype that promises automatic success without a result.
